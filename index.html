Problem

The rapid spread of misinformation online poses a serious challenge to public discourse. There was no accessible, automated tool that could reliably classify news content as genuine or fake using modern NLP and machine learning techniques.

Process

Designed and built an end-to-end ML pipeline across seven stages: data collection, cleaning, preprocessing, NLP tokenization, TF-IDF feature extraction, Logistic Regression model training and evaluation, and final prediction.

Result

Delivered a fully functional modular pipeline capable of classifying news articles with measurable accuracy. Integrated the trained model into a Django-based web application that provides real-time classification results and user-facing insights.

Key Outcomes
  • End-to-end ML pipeline covering preprocessing, feature engineering, training, evaluation, and prediction
  • Applied TF-IDF vectorization and NLP tokenization
  • Logistic Regression classifier trained and evaluated against real-world news datasets
  • Modular pipeline design for maintainability and extensibility
  • Live Django web app with real-time classification
  • Validation and debugging throughout every pipeline stage
